# 📝 Task Manager App (React + TypeScript)

A simple task management app built with **React**, **TypeScript**, and **CSS Modules**. Add, complete, and delete tasks with a clean interface and persistent UI behavior.

## 🚀 Features

- ✅ Add tasks using the input box
- 🔄 Click on a task to toggle its status (incomplete/complete)
- ❌ Delete tasks with a single click
- 🎨 Responsive and themed design using CSS Modules
- ⚙️ Type-safe state management with `useReducer`
